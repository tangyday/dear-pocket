# 디어포켓 (Dear Pocket)
모바일 우선 정적 웹 가계부. Firebase Authentication 및 Cloud Firestore 사용.

## 설치
1. https://console.firebase.google.com 에서 프로젝트 생성, 웹 앱 등록.
2. 프로젝트 설정에서 웹 앱 firebaseConfig 값을 복사하여 `firebase-config.js`의 자리표시자를 교체.
3. Authentication > Sign-in method에서 이메일/비밀번호 활성화.
4. Firestore Database를 생성하고 Rules 탭에 `firestore.rules` 내용을 붙여넣어 게시. 테스트 모드의 공개 규칙을 사용하지 마세요.
5. GitHub 저장소 루트에 이 폴더 안 파일들을 업로드. Settings > Pages > Deploy from a branch > main / (root) > Save.
6. Authentication > Settings > Authorized domains에 `계정명.github.io` 추가. 사이트를 HTTPS 주소로 열어 회원가입 후 로그인.

## 사용법
- 25일~다음 달 24일 기준. 새 기간을 최초로 열면 가장 최근 이전 기간의 월급, 고정비, 생활비/쇼핑/저축 목표를 복사합니다. 이미 생성된 기간은 별도 수정해야 합니다. 일별 기록은 복사하지 않습니다.
- 상단 잔액은 고정비/특별지출 및 남은 저축 목표까지 확보하고 남은 돈. 하루 예산은 생활비 잔액을 오늘 포함 남은 일수로 나눈 값입니다. 이미 지난 기간은 하루 예산 0원. 예산 초과 시 미배정 항목은 음수로 표시됩니다.
- 기록 추가/삭제 시 Firestore 실시간 구독으로 갱신. 실제 저축은 목표와 중복 차감하지 않습니다.
- 예산 항목은 저장 버튼으로 확정. 로그인 계정별 데이터는 Firestore 보안 규칙으로 분리됩니다. GitHub 저장소에는 실제 가계부 기록이나 비밀번호를 올리지 마세요. 신규 계정은 예산 설정에서 직접 금액을 입력하세요.
- Firebase 설정은 공개 웹 클라이언트용 값입니다. 서비스 계정 비밀키는 절대 업로드하지 마세요. Firebase 사용량과 요금은 콘솔에서 확인하세요.

실제 Firebase 연결은 사용자의 프로젝트 설정 이후 가능합니다. 이 파일에는 실제 계정/프로젝트 키가 포함되어 있지 않습니다.

## 사랑스러운 테마 업데이트
월별 가계부에서 날짜별 기록, 지출 합계, 분류 필터를 볼 수 있습니다. 기존 Firestore 데이터 구조는 변경하지 않았습니다.

## v4 업데이트
- 하단 메뉴: 홈, 가계부, 기록, 통계, 설정.
- 달력은 매월 25일~다음 달 24일 기준이며 날짜를 선택하면 목록을 필터링합니다.
- 기록 시 세부 카테고리를 선택할 수 있습니다. 기존 기록은 기존 예산 구분을 기준으로 기본 카테고리에 표시합니다.
- 통계는 생활비·쇼핑·특별지출(예정 포함)을 집계하고 고정비 포함 총액을 별도 표시합니다.
- 공개 GitHub 저장소에 개인 재정정보가 노출되지 않도록 신규 계정의 초기 예산은 0원입니다. 기존 Firebase 데이터는 그대로 유지됩니다.
- 기존 배포를 업데이트할 때는 이미 설정한 firebase-config.js를 덮어쓰지 마세요. 기존 Firestore 경로 및 규칙은 동일합니다.


## 브랜드 적용
- 앱 이름을 **디어포켓 (Dear Pocket)** 으로 적용했습니다.
- `favicon.svg` 파일이 포함되어 있어 브라우저 탭 아이콘(파비콘)으로 바로 사용됩니다.
- 헤더에 아이콘 + 앱명 + 소개문구를 적용했습니다.
